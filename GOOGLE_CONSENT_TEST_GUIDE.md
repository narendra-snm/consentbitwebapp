# ConsentBit — Test Account Guide for Google Additional Consent

This guide explains how to log in to the ConsentBit test account and verify the
**Google Additional Consent** integration. A pre-configured test account has been
created for review.

---

## 1. Test Account Credentials

Use the following credentials to sign in:

| Field | Value |
|-------|-------------------|
| Email | `test@consentbit.com` |
| PIN   | `424242` |

> These credentials are for testing the Google Additional Consent feature.

---

## 2. Signing In

1. Open the ConsentBit web app in your browser https://accounts.consentbit.com/login.
2. Enter the email **`test@consentbit.com`**.
3. Enter the PIN as login code **`424242`**.
4. Continue to the dashboard.

---

## 3. Testing Google Additional Consent

Once signed in, you can review the Google Additional Consent setup on the
configured site. The default test site is already connected to the account, so
you can begin testing immediately.

---

## 4. Changing the Site URL (Optional)

If you would like to test against **your own domain** instead of the default test
site, you can update the domain from the account profile:

1. Go to **Profile**.
2. Open **Organizations**.
3. Click **Manage**.
4. Select **Change the domain**.
5. Enter your domain and save.

After updating the domain, you can run the Google Additional Consent test on your
own site.

---

If you run into any issues during testing, please reach out to the ConsentBit
